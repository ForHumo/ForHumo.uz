## 🔴 Topilmalar

### 1. Checkout manzil — xarita bilan tanlanmaydi
- **Muammo:** Buyurtma rasmiylashtirilayotganda yetkazish manzili faqat yozma matn (input) sifatida
  kiritilmoqda. Kuryerlar (asosan viloyatdan kelganlar) Toshkent yozma manzillarini tushunmaydi,
  bu esa yetkazishga to'siq bo'ladi.
- **Ta'sir:** kritik (yetkazish oqimini buzadi, xaridor xafa bo'ladi, sotuvchi ham zarar)
- **Yechim rejasi:**
  - `bn-checkout-modal.tsx` va `bn-addresses` bo'limlarida yozma input o'rniga xarita picker qo'yish.
  - **Provayder:** Google Maps (afzallik) yoki Yandex Map. Foydalanuvchi Google Maps pullik bo'lsa to'lashga tayyor.
  - Foydalanuvchi joriy lokatsiyaga tez o'tish + qidiruv + qo'lda pin qo'yish.
  - `BnAddress` modeliga `lat` + `lng` maydonlari qo'shish (Prisma migratsiya).
  - Saqlangan manzilda ham xarita ko'rinishi + kuryer uchun marshrut linki.
- **Status:** ochiq

### 2. Sotuvchi arizasida manzil — xarita bilan tanlanmaydi
- **Muammo:** `bn-seller-register.tsx` da do'kon manzili yozma matn. Xaridor "Olib ketish" qilganda
  aynan qayerga borishini bilmaydi, do'kon ham xaritada topilmaydi.
- **Ta'sir:** kritik (do'kon topilmasa "Olib ketish" varianti amalda ishlamaydi)
- **Yechim rejasi:**
  - Ariza formasida xarita picker.
  - `BnShop` modelida allaqachon `address` bor — `lat` va `lng` qo'shish.
  - Do'kon sahifasida `bn-pages.tsx BnShopPage` — xarita kartasi va "Yo'l ko'rsatish" tugmasi.
  - Bozor sahifasida ham bozor lokatsiyasini xarita bilan ko'rsatish (`BnMarket` da qo'shish).
- **Status:** ochiq

### 3. Global For Humo Header/Footer bozornarxida.uz'da qo'shimcha DOM chiqarayapti
- **Muammo:** `src/app/[locale]/layout.tsx` root komponentida `<Header />` va `<Footer />` `publicHost` bo'lsa ham render qilinardi. BN moduli `fixed inset-0 z-[100]` bilan ustidan qoplaydi (visual), lekin DOM'da ular qoladi va Next.js RSC prefetch qiladi.
- **Ta'sir:** kritik. Har sahifada 2 ta 404 (`/uz/id/edit?_rsc=...`, `/uz/privacy-policy?_rsc=...`) + React hydration mismatch (error #418).
- **Yechim:** `!publicHost && <Header />` shartli render.
- **Status:** ✅ tugatildi (test paytida topilib, darhol fix'landi)

### 4. React error #418 (hydration mismatch)
- **Sabab:** ehtimol yuqoridagi qatlam ziddiyati bilan bog'liq (Header/Footer DOM'da bo'lib client'da qayta render bo'ldi).
- **Ta'sir:** kritik (lekin transparent — sayt ishlayapti, ammo qayta render bilan sekin).
- **Status:** yuqoridagi fix bilan hal bo'lishi kerak, keyingi deployda tekshiriladi.
